[인사이트] 모듈형 멀티-플랫폼

  • • Gateway 중심 설계: Discord, Telegram, CLI가 동일한 'Core Agent Loop'를 공유합니다.
  • • LLM 독립성: 특정 모델(Claude, Gemini 등)에 종속되지 않고 유연한 스위칭이 가능합니다.

[파급효과] 도구와 지식의 축적

  • • Tools & Skills: 단순 챗봇이 아닌 터미널, 브라우저 제어가 가능하며 `oh-my-jeo` 등 사용자 스킬을 영구 학습합니다.
  • • 지속성: SQLite와 FTS5를 통해 세션 데이터를 장기 기억으로 연결합니다.

[전망] 자율운영의 고도화

  • • Cron & Kanban: 사용자가 접속하지 않아도 정해진 시간에 스스로 작업을 수행하고 보고하는 완전 자율화.
  • • Subagent: 작업을 쪼개어 하위 에이전트(Delegation)에 위임하는 멀티 에이전트 시대에 최적화된 프레임워크입니다.
